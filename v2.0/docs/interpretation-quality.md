# 일본어 → 한국어 실시간 통역 품질 검토

짧은 한 문장으로는 긴 대화의 문맥 유지, 존댓말 일관성, 부정·기한·담당자 정확도를 판정할 수 없습니다. 먼저 일본어 전사가 맞는지와, 맞는 원문을 한국어로 옮기는지를 분리해 평가해야 합니다. 음성 인식이 `しない`를 `する`로 잘못 전사하면 번역 모델의 문맥만으로 복구할 수 없으며, 원문에 없는 결론을 추측하게 해서는 안 됩니다.

| 문제 | 이번 적용 | 남은 검증 또는 대안 |
| --- | --- | --- |
| 짧은 회의에서 과거 발언이 보이지 않음 | 발언마다 타임라인 카드 하나를 만들고 일본어·한국어 미리보기, 처음/최근 이동, 수동 선택을 제공. 이전 발언은 새 번역 중에도 유지. | 10분 이상 회의에서 자동 스크롤과 수동 탐색을 실기 확인. |
| 발언 중 원문 수정과 번역 불일치 | 같은 발언의 일본어가 수정되면 오래된 한국어를 즉시 지우고 재번역. 완료된 앞 발언은 보존. | 지연과 정정 빈도를 실제 회의 음성으로 측정. |
| 용어·호칭·어조의 단절 | 완료된 직전 JA/KO 두 발언만 번역 요청의 문맥으로 전달. 모델에는 현재 문장만 출력하고, 앞 문장을 반복하거나 미완성 발언을 추측하지 않도록 지시. 일본어 종결 표현에 따라 반말/존댓말/원문 유지 목표를 지정. | 전문 용어 사전, 회의별 사용자 설정, 화자 구분은 별도 설계·동의·품질 평가 후 적용. 문맥을 무제한 늘리면 지연과 메모리가 증가하므로 현재는 두 발언으로 제한. |
| 입력 불안정과 누락 | 컴퓨터 소리 초기화가 멈추면 앱이 15초 안에 오류를 표시하도록 동기 Core Audio 작업을 분리. 실시간 통역에서 컴퓨터 소리를 요청했는데 시작에 실패하면 마이크만으로 조용히 계속하지 않음. | 해당 Mac의 Core Audio 지연 원인과 다른 출력 장치·두 번째 Mac에서의 재현 확인. 브라우저 음성 입력은 별도 경로로 검증. |

품질 승인에는 정답이 있는 10–20분 일본어 회의 샘플이 필요합니다. 격식체와 일상체, 고유명사·용어, 부정문, 미정인 담당자와 마감일, 발언 중 정정, 무음과 겹친 발언을 포함하고, 일본어 전사 오류와 한국어 통역 오류를 따로 기록합니다. 통역 시작부터 화면 표시까지의 지연, 잘못된 정정 비율, 과거 타임라인 탐색, 30–60분 메모리 사용량, 마이크·컴퓨터 소리·혼합 입력을 각각 측정해야 합니다. 현재의 짧은 로컬 샘플과 두 문장 모델 점검은 이 승인 기준을 충족하지 않습니다.
