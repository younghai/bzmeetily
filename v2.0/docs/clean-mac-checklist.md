# 깨끗한 Mac 최종 검증 체크리스트 (T08)

대상: 개발 도구(Node/Bun/Python/Homebrew)가 설치되지 않은 Apple Silicon Mac, macOS 14.2 이상.
검증자: 각 항목 끝에 날짜·결과를 기록합니다.

## 0. 준비

- [ ] macOS 버전 확인: `sw_vers` (14.2+)
- [ ] 칩 확인: `uname -m` → arm64
- [ ] 여유 디스크 15GB 이상
- [ ] 테스트용 일본어 음성 준비 (영상 재생 or 마이크 발화)

## 1. 설치

- [ ] DMG를 열어 Meetily2를 Applications로 드래그
- [ ] `spctl -a -t exec /Applications/Meetily2.app` (배포 빌드: accepted / dev 빌드: quarantine 경고 확인)
- [ ] 앱 첫 실행이 정상적으로 창을 띄움 (dev 빌드는 우클릭 → 열기)
- [ ] 원본 Meetily(`meetily.app`)가 같은 Mac에 있어도 서로 간섭 없음 (아이콘, 창, 데이터)

## 2. 첫 실행 — 모델 설치

- [ ] 모델 설치 화면이 자동으로 표시됨
- [ ] 저장 공간 표시(여유/필요)가 실제와 일치
- [ ] Whisper 다운로드 진행률 표시, 완료 시 "설치됨"
- [ ] 다운로드 중 네트워크 차단 → 오류 안내 → 재개 시 처음부터가 아닌 이어받기 (파일 크기로 확인)
- [ ] Qwen 다운로드 진행률 표시, 완료 시 "설치됨"
- [ ] 두 모델 완료 후 "권한 설정으로 이동" 활성화

## 3. 권한

- [ ] 마이크 권한 안내 → 시스템 설정에서 허용 → 복귀
- [ ] 통역 시작 시 컴퓨터 소리(화면 기록/오디오 캡처) 권한 요청 → 허용 후 재시작 안내 처리
- [ ] 권한 거부 상태에서 시작 시도 → 명확한 안내 문구 + 복구 경로 표시

## 4. 실시간 통역 (핵심)

- [ ] 모드 선택 화면에서 "실시간 통역" 선택 → 좌: 일본어 / 우: 한국어 대기 화면
- [ ] 입력 소스 "컴퓨터 소리 + 마이크" 기본값 확인
- [ ] 일본어 영상 재생 → 첫 일본어 자막 약 2초 내 표시, 이어서 한국어 표시
- [ ] 연속 발화 중 자막이 뒤 문맥으로 보완·갱신됨 (웹 버전과 동일 기준)
- [ ] 무음 0.24초 후 구간 확정, 긴 발언은 8초 경계에서 분할
- [ ] 마이크 동시 입력 확인 (시스템 소리 + 내 목소리 모두 자막화)
- [ ] 30~60분 연속 통역: 대기열 증가 없음, 메모리 안정, 자막 지연 증가 없음
- [ ] 통역 중지 → 남은 문장 처리 후 자막 유지
- [ ] 통역 내용이 회의 DB/녹음 파일로 저장되지 않음 확인
- [ ] 다시 시작 → 이전 자막 초기화, 재입력 정상
- [ ] 입력 장치 분리·재연결(블루투스 이어폰 등) → 복구 또는 안내 표시

## 5. 회의 녹음 모드

- [ ] 새 회의 생성 → 녹음 → 중지 → 전사/요약/번역 표시
- [ ] 요약 생성(로컬 Qwen) 동작
- [ ] 일본어 음성 파일 가져오기(WAV/MP3) → 전사·번역·재생
- [ ] 앱 재시작 후 회의 목록 유지

## 6. 서비스 런타임

- [ ] 앱 실행만으로 localhost:3118 상태 API 응답 (`curl http://127.0.0.1:3118/api/local/status`)
- [ ] whisper:8178 /health 응답, ollama:11434 /api/version 응답
- [ ] 브라우저에서 http://localhost:3118 접속 → 동일 UI 동작
- [ ] 앱 종료 시 세 서비스 프로세스 함께 종료 (`lsof -i :3118,:8178,:11434` 비움)
- [ ] 앱 재실행 → 중복 프로세스/포트 오류 없이 준비
- [ ] (선택) 사용자가 별도 Ollama를 띄운 상태에서 앱 실행 → 해당 서비스 재사용, 충돌 없음

## 7. 재부팅·업데이트

- [ ] Mac 재부팅 후 앱 실행 → 모델 재다운로드 없이 바로 통역 가능
- [ ] 앱 재설치(덮어쓰기) 후에도 모델·회의 데이터 보존 (사용자 데이터 영역 분리 확인)
- [ ] 원본 Meetily와의 데이터(~/Library/Application Support/com.meetily.ai) 무손상
