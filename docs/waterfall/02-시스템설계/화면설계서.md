## 1. 문서 개요

### 1.1 목적

사용자 화면별 행동, 표시 정보와 확인 기준을 정의한다.

### 1.2 적용 범위와 독자

모드 선택, 좌우 통역, timeline, 회의 내용, 첫 실행과 macOS 창을 다룬다. 제품 기획·개발·QA·릴리스 검토자가 사용한다.

### 1.3 기준과 판정

이 문서는 2026-09-25의 소스와 기록을 바탕으로 한 **검토 초안**이다. 문서화·코드 구현·실행 검증·일반 배포 승인은 서로 다른 상태다.

---

## 2. 디자인 원칙

일본어 원문과 한국어 번역을 동시에 읽을 수 있는 크기로 보여 준다. 현재 발화와 이전 timeline을 분리하고, 처리 중·실패·완료 상태를 텍스트와 구조로 구분한다. RC6 창 컨트롤은 macOS 표시와 겹치지 않도록 실제 빌드 Mac에서 확인되었지만 다른 해상도 전체 검증은 남아 있다.

---

## 3. 레이아웃 구조

시작 화면은 통역·녹음 모드 선택을 분리한다. 통역 화면은 좌측 일본어, 우측 한국어와 발화별 timeline을 제공한다. 긴 대화와 좁은 창에서 콘텐츠가 잘리지 않도록 각 영역은 스크롤 가능해야 한다. macOS 상단 좌측 창 컨트롤을 위한 여백을 유지한다.

---

## 4. 화면 상세 설계

| 화면 | 사용자 동작과 표시 | 수용 확인 |
| --- | --- | --- |
| 모드 선택 | 실시간 통역 또는 회의 녹음 선택. 선택만으로 캡처 시작 금지. | 선택 전·후 OS 입력 표시와 앱 상태 확인 |
| 실시간 통역 | 입력원 선택·시작/중지, 왼쪽 일본어 전사·오른쪽 한국어 통역, 처리/오류 표시. | 컴퓨터 소리·마이크·혼합 각각 실제 음성 확인 |
| timeline | 완료 발화의 순서·원문·번역을 스크롤로 유지, 첫/최근 이동. | 여러 발화 후 첫 발화 재조회·번역 갱신 확인 |
| 회의 목록/상세 | 녹음·가져오기, 시간 순 전사, 오디오, 요약 요청·결과. | 파일 가져오기→전사→회의록 E2E |
| 첫 실행/설정 | 모델 다운로드 상태와 권한 안내. | 깨끗한 Mac에서 설치·거부·재시도 |
| macOS 창 | 닫기·최소화·전체 화면 컨트롤과 사이드바 콘텐츠가 겹치지 않음. | 보통/확장/전체 화면 상태의 실제 조작 |

---

## 5. 공통 컴포넌트와 상태

입력원 선택, 시작/중지, 모델 준비 상태, 전사 중 표시, 번역 중 표시, 번역 오류·재시도, 발화 카드, 첫/최근 이동을 공통 상호작용 단위로 취급한다. 상태는 원문·번역을 같은 발화 ID에 연결한다. [UI 구현](../../../v2.0/meetily/frontend/src/local/components/InterpretationView.tsx)을 참조한다.

---

## 6. 인터랙션 패턴

모드 선택만으로 캡처하지 않는다. 통역 중 이전 카드를 선택한 사용자가 새 발화로 인해 강제로 최신 위치로 이동하지 않아야 한다. 사용자가 최신 이동을 선택하면 현재 발화로 돌아간다. 원문이 수정되는 동안 낡은 번역을 보이지 않게 한다.

---

## 7. 창 크기와 접근성

작은 창과 전체 화면에서 버튼·좌우 텍스트·timeline 탐색을 확인한다. 닫기/최소화/전체 화면과 키보드 초점 이동이 가능한지 실제 앱에서 검증한다. 색만으로 오류를 구별하지 않고 텍스트 설명을 제공한다.

통역 화면에서 새 발화가 진행되어도 이전 발화가 화면에서 사라지지 않아야 한다. 긴 문장은 한 단어 폭으로 잘리지 않도록 좌우 자막 영역이 충분한 폭·높이를 사용하고, 작은 창에서는 스크롤 가능해야 한다. 색만으로 전사/번역/오류를 구분하지 않는다. 실제 UI 구현: [InterpretationView.tsx](../../../v2.0/meetily/frontend/src/local/components/InterpretationView.tsx), [SessionModeChooser.tsx](../../../v2.0/meetily/frontend/src/local/components/SessionModeChooser.tsx). 최근 창 컨트롤 검증 범위: [RC6 노트](../../../v2.0/docs/release-2.0.2-rc.6.md).

## 8. 검증 근거와 미해결

[RC6 노트](../../../v2.0/docs/release-2.0.2-rc.6.md)는 빌드 Mac의 창 컨트롤·사이드바·통역 제목 배치 검증을 기록한다. 긴 대화·브라우저별·다양한 창 크기 접근성 시험은 [테스트 케이스](../05-테스트/테스트케이스.md)에 남아 있다.
