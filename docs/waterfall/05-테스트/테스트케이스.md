# 테스트 케이스

각 실행에는 후보 버전, Mac/OS, 입력원·모델 버전, 실제/예상 결과, 로그·화면 증거, 개인정보 제거 여부를 기록한다. 아래는 **계획된 수용 케이스**이며 모두 통과했다는 뜻이 아니다.

| ID | 실행 | 기대 결과 |
| --- | --- | --- |
| TC-01 | 앱 시작, 통역/녹음 모드 전환, 시작 버튼 전 OS 오디오 표시 확인 | 선택만으로 캡처되지 않음 |
| TC-02 | 일본어 테스트 발화를 컴퓨터 소리, 마이크, 혼합으로 각각 입력; 컴퓨터 소리 권한 거부도 실행 | 각 입력의 전사가 보임; 권한 거부는 명시적 오류, 몰래 mic-only 전환 없음 |
| TC-03 | 여러 발화 중 느린 ASR/번역 응답을 섞고 원문을 수정 | 일본어·한국어 짝과 순서 보존, 낡은 번역 미표시 |
| TC-04 | 긴 일본어 대화 후 timeline 처음/최근 이동, 창 크기 변경 | 이전 카드 보존·스크롤·문장 가독성 확인 |
| TC-05 | 회의 녹음→중지→재열기, 동일 청크 순번 재전송 | 오디오·전사 재조회, 중복 세그먼트 없음 |
| TC-06 | 음성 파일 가져오기→전사 검토→한국어 요약; 빈 전사도 요청 | 실제 회의록 재조회, 빈 전사는 409 |
| TC-07 | 같은 Mac의 localhost를 실제 브라우저에서 열고 권한 승인/거부 및 마이크 발화 | 자막 흐름 작동 또는 브라우저별 제한 명시 |
| TC-08 | 로컬 서버 포트/Origin/변경 요청 검사 | loopback 바인딩·허용 origin/헤더 규칙 확인 |
| TC-09 | 30~60분 음성·무음·혼합 입력, 시간별 RSS/압력·지연·누락·오류 기록 | 수치와 실패 샘플 확보, 회복 가능한 처리 |
| TC-10 | 새 Mac에 서명·공증 DMG 설치, 모델 다운로드, 권한·통역·회의록 실행 | 설치부터 핵심 기능까지 차단 문제 없음 |

성능/정확도 TC-09는 수치 수집 후 합격 기준을 별도 확정한다. 현재 [RC6 검증](../../../v2.0/docs/release-2.0.2-rc.6.md)은 TC-02/04/10 전체 통과 증거가 아니다.
