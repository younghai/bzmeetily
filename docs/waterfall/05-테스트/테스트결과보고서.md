## 1. 문서 개요

### 1.1 목적

기존 RC4·RC6 검증 기록과 아직 없는 증거를 분리한다.

### 1.2 적용 범위와 독자

문서 작성 시점의 기존 테스트 기록만 재정리하며 이번 문서 수정은 앱 재시험이 아니다. 제품 기획·개발·QA·릴리스 검토자가 사용한다.

### 1.3 기준과 판정

이 문서는 2026-09-25의 소스와 기록을 바탕으로 한 **검토 초안**이다. 문서화·코드 구현·실행 검증·일반 배포 승인은 서로 다른 상태다.

**기준일:** 2026-09-25. 아래는 기존 [3회 점검](../../../reviews/STATE.md)과 [RC6 노트](../../../v2.0/docs/release-2.0.2-rc.6.md)의 확인된 결과만 재정리했다. 이 문서 작성 자체로 앱 테스트를 재실행한 것은 아니다.

## 2. 테스트 실행 요약

| 항목 | 기록된 결과 | 한계/판정 |
| --- | --- | --- |
| RC4 로컬 소스 테스트 | 프런트엔드 93 통과·1 건너뜀, Rust 253 통과·4 ignored; 하드웨어 조회 2건은 Mac의 hang 후 필터 | 소스 회귀 증거, 전체 하드웨어 통과 아님 |
| RC4 빌드/서비스 | TypeScript·Rust release check·프런트/Tauri 빌드, Whisper/Ollama 스모크 추론 통과 | 새 Mac 검증 아님 |
| RC4 네이티브 혼합 입력 | 빌드 Mac에서 26초 재생으로 일본어/한국어 timeline 카드 4개 보존 | 조용한 구간 ASR 환각 관찰, 정확도 미통과 |
| RC6 앱 UI·패키지 | 빌드, DMG 이미지/checksum/ad-hoc 서명, 실제 창 컨트롤·사이드바·통역 제목 배치 및 창 동작 확인 | RC6 음성 정확도는 재측정하지 않음 |
| 브라우저 캡처 | UI/코드 존재 | 인앱 브라우저 마이크 E2E 미검증 |
| 장시간·회의록·배포 | 30~60분 메모리, 새 후보 회의/요약 E2E, 첫 모델 다운로드, 다른 Mac, Developer ID 서명·공증 미완료 | 일반 배포 차단 |

---

## 3. 레벨별 결과

RC4의 프런트엔드·Rust 단위 검사는 소스 회귀를 보여 준다. Whisper/Ollama 스모크는 로컬 서비스가 짧은 요청을 처리했음을 보여 준다. RC4의 26초 네이티브 혼합 입력은 카드 4개 보존을 보여 준다. RC6의 창 동작 검사는 UI 배치를 보여 주지만 RC6 장시간 오디오 품질을 증명하지 않는다.

## 4. 결함 분석

| 관찰 | 영향 | 현재 상태 |
|------|------|-----------|
| 무음 구간 ASR 환각 | 없는 발언이 전사·번역될 수 있음 | 원인·감소율 미검증 |
| 과거 Core Audio 시작 지연 | 입력 시작 실패 가능 | RC4에 bounded wait 적용, 다른 Mac 검증 필요 |
| RC5 창 컨트롤 겹침 | 창 조작 불편 | RC6 빌드 Mac에서 배치 수정 확인 |
| 브라우저 마이크 E2E 미실행 | localhost 통역 완결성 불명 | 릴리스 게이트 개방 |

---

## 5. 성능 결과

30~60분 세션의 RSS·메모리 압력·큐 길이·전사/번역 p50·p95가 아직 측정되지 않았다. 짧은 시연을 장시간 안정성 결과로 옮기지 않는다.

---

## 6. 보안과 배포 결과

RC6의 DMG checksum·이미지·ad-hoc 서명은 확인됐다. Developer ID 서명·공증, 다른 깨끗한 Mac 설치·권한은 미완료다. loopback 보안은 소스·스모크 근거가 있으나 일반 배포 환경에서 재확인한다.

---

## 7. UX와 접근성 결과

RC6 빌드 Mac에서 창 컨트롤, 사이드바, 통역 제목의 겹침 여부와 전체 화면·최소화·닫기 동작을 확인했다. 긴 자막, 다양한 창 크기, 브라우저 키보드/마이크 흐름은 이 후보에서 종합 검증되지 않았다.

---

## 8. 커버리지와 종료 기준

테스트 수량은 RC4 소스 검사에 한정된다. RC6의 새 후보 통역 정확도, 회의록 E2E, 브라우저·clean-Mac·장시간 시험은 미실행이므로 [테스트 계획](테스트계획서.md)의 일반 배포 종료 기준은 충족되지 않았다.

---

## 9. 결론과 권고

**현재 게이트:** 개발 후보로만 사용 가능. 혼합 입력의 여러 실제 환경 정확도, 조용한 구간 환각, 장시간 메모리, 네이티브와 브라우저 E2E, 서명·공증·깨끗한 Mac 설치가 남아 있다. 최신 상태가 바뀌면 해당 후보의 테스트 증거 링크·날짜와 함께 이 표를 갱신한다.

다음 측정은 혼합 오디오·무음 환각을 원음 대조로 재현하고, 30~60분 메모리·지연을 기록하며, 새 후보의 회의록/브라우저/별도 Mac을 검증하는 순서다.
