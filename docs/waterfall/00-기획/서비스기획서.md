# 서비스 기획서

**제품:** Meetily2 · **범위:** Apple Silicon macOS 앱과 같은 Mac의 localhost UI · **기준:** 2026-09-25

## 문제와 목표

일본어로 진행되는 회의에서 사용자가 컴퓨터 소리와 마이크를 들으며 내용을 놓치지 않도록 일본어 인식 결과와 한국어 통역을 대화 순서대로 제공한다. 회의 후에는 별도 녹음·가져오기 흐름에서 전사와 한국어 회의록을 검토한다. 핵심 사용자는 일본어 회의 참여자와 한국어로 기록을 확인하는 사용자다.

## 제품 흐름

1. 첫 실행에서 로컬 Whisper와 Ollama 모델을 준비하고 필요한 macOS 권한을 확인한다.
2. 시작 화면에서 **실시간 통역** 또는 **회의 녹음**을 고른다. 모드 선택만으로 음성 수집은 시작하지 않는다.
3. 실시간 통역에서는 입력원(컴퓨터 소리·마이크·둘 다)을 고르고 시작한다. 왼쪽 일본어, 오른쪽 한국어, 이전 발화 timeline을 확인한다. 이 경로는 회의 파일 생성이 목적이 아니다.
4. 녹음·가져오기에서는 전사 내용을 검토한 뒤 한국어 요약을 생성한다. 음성·전사·요약은 사용자의 로컬 환경에서 다룬다.
5. 앱이 실행 중이면 같은 Mac의 `http://127.0.0.1:3118/`에서 localhost UI를 사용할 수 있다. 브라우저 캡처는 별도 경로이므로 네이티브 캡처 성공을 그대로 적용하지 않는다.

## 성공 기준과 비목표

성공 기준은 통역의 **발화 순서 유지·이전 대화 보존**, 양쪽 입력원의 실제 동작, 측정된 지연·정확도·메모리, 전사/회의록 E2E, 안전한 Mac 설치다. 수치 목표와 합격 기준은 [테스트 계획](../05-테스트/테스트계획서.md)에서 기준선 측정 후 정한다. 현재 측정되지 않은 수치를 성능 보장으로 표기하지 않는다.

이 단계의 범위에는 Windows/Intel 배포, 서버 기반 공동 작업, 실시간 음성 합성 통역, 무검토 자동 회의록 확정이 없다. 모델 출력은 초안이며 중요한 내용은 사용자가 확인한다.

## 현재 제품 상태

RC6는 개발용 미리보기다. 빌드 Mac의 통역 timeline과 UI 일부는 확인됐으나 혼합 오디오 정확도, 긴 세션 메모리, 브라우저 마이크, 새 후보의 회의록 E2E, 서명·공증·다른 Mac 설치가 남아 있다. [상태 기록](../../../reviews/STATE.md)을 배포 판정의 기준으로 삼는다.
