# 제품·운영 정책

## 입력과 저장

- 실시간 통역과 회의 녹음은 사용자가 명시적으로 선택하고 시작한다. 모드 선택 자체가 자동 녹음을 뜻하지 않는다.
- 실시간 통역의 자막·timeline은 세션 중 대화 확인을 위한 것이다. 회의 데이터로 남기려면 제공된 복사/내보내기 기능이나 별도 회의 녹음 흐름을 사용한다.
- 녹음·가져오기에서는 로컬 회의 DB와 오디오 파일을 사용한다. 삭제·백업·보관 기간에 대한 사용자 대상 정책은 아직 별도 승인된 정책이 없으므로 임의의 보존 기한을 약속하지 않는다.
- 개인 오디오, 모델, DB, 비밀값, 빌드 산출물은 Git 저장소에 넣지 않는다.

## 모델 출력과 신뢰도

- 일본어 ASR, 한국어 통역, 요약은 자동 생성 결과다. 음원이 조용할 때도 ASR 환각이 관찰되었으므로 중요한 발언, 이름, 숫자, 결정 사항은 원음과 대조한다.
- 번역에는 최근 완료된 두 발화까지 문맥을 줄 수 있지만, 이 설계만으로 정확도가 보장되지는 않는다. 번역 오류는 원문과 연결해 표시하고 이전 발화가 사라지지 않아야 한다.

## 배포 정책

- ad-hoc 서명 RC6는 신뢰된 테스트 Mac용 개발 후보로만 소개한다. 일반 배포는 Developer ID 서명·공증, 깨끗한 다른 Mac의 첫 실행·권한·모델 설치, 실오디오·장시간 테스트 후 결정한다.
- [릴리스 게이트](../06-배포/배포계획서.md)의 미충족 항목을 통과로 간주하지 않는다. 기존 DMG를 덮어쓰거나 일반 배포 상태로 이름을 바꾸지 않는다.
