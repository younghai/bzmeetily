# 소프트웨어 요구사항 명세서 (SRS)

**판정 용어:** `구현`은 소스에 경로가 있음을, `부분 검증`은 제한된 장비·시나리오의 실행 증거가 있음을, `미검증`은 릴리스 합격 증거가 부족함을 뜻한다. 요구사항은 제품 기준이며 아래 상태가 승인 기록은 아니다.

| ID | 요구사항과 수용 기준 | 현재 상태 |
| --- | --- | --- |
| FR-01 | 사용자가 통역/회의 녹음 모드를 선택한 뒤 별도로 시작해야 음성 캡처가 열린다. | 구현, 부분 검증 |
| FR-02 | 네이티브 통역에서 마이크·컴퓨터 소리·혼합 입력원을 선택한다. 요청한 컴퓨터 소리가 실패하면 오류를 알리고 조용히 마이크만 쓰지 않는다. | 구현, 혼합 정확도 미검증 |
| FR-03 | 일본어 음성의 전사를 원문으로 표시하고 발화의 순서를 유지한다. | 구현, 부분 검증 |
| FR-04 | 해당 일본어 발화의 한국어 번역을 오른쪽에 연결해 표시하고, 수정된 원문의 낡은 번역을 제거한다. | 구현, 부분 검증 |
| FR-05 | 새 발화가 들어와도 이전 발화 timeline이 남고 처음/최근 발화로 이동할 수 있다. | 구현, 짧은 시나리오 검증 |
| FR-06 | 회의 음성을 녹음하거나 파일로 가져와 로컬 전사와 오디오를 저장·재조회한다. | 구현, 새 후보 E2E 미검증 |
| FR-07 | 저장된 전사를 바탕으로 로컬 한국어 요약을 생성·재조회한다. | 구현, 새 후보 E2E 미검증 |
| FR-08 | 앱 실행 중 같은 Mac에서 localhost UI에 접속한다. 브라우저 음성 입력은 해당 브라우저 권한과 공유 기능에 따른다. | UI 구현, 브라우저 캡처 미검증 |
| FR-09 | 첫 실행에서 필요한 모델·권한의 상태를 보여주고 설치/거부/오류를 복구할 수 있다. | 구현, 다른 Mac 미검증 |
| NFR-01 | 로컬 서비스는 loopback에 바인딩하고 공개 네트워크에 열리지 않아야 한다. | 코드·스모크 검사, 운영 재확인 필요 |
| NFR-02 | 실오디오 지연·정확도는 원문/번역별로 측정해 합격 기준을 정한다. | 기준선·다조건 측정 미완료 |
| NFR-03 | 30~60분 세션 동안 메모리·큐·timeline이 안정적으로 동작한다. | 미검증 |
| NFR-04 | 일반 배포 DMG는 Developer ID 서명·공증과 다른 Mac 설치/권한 테스트를 통과한다. | 미충족 |

자세한 사용자 흐름은 [유스케이스](유스케이스명세서.md), 구현·시험 연결은 [RTM](요구사항추적매트릭스-RTM.md), 증거는 [결과 보고서](../05-테스트/테스트결과보고서.md)를 본다.
