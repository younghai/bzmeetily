## 1. 문서 개요

### 1.1 목적

남은 검증과 개선을 릴리스 영향 순서로 정리한다.

### 1.2 적용 범위와 독자

P0 일반 배포 차단 항목과 후속 P1·P2 항목을 다룬다. 제품 기획·개발·QA·릴리스 검토자가 사용한다.

### 1.3 기준과 판정

이 문서는 2026-09-25의 소스와 기록을 바탕으로 한 **검토 초안**이다. 문서화·코드 구현·실행 검증·일반 배포 승인은 서로 다른 상태다.

이 목록은 검증·개선 순서이며 확정 일정이나 구현 완료 선언이 아니다.

---

## 2. 로드맵 개요

이 문서는 확정 일정이 아닌 검증 순서다. P0는 일반 배포 전 해결해야 할 차단 항목, P1은 품질 완결, P2는 승인되지 않은 제품 정책과 운영 개선이다. 담당자·기한은 아직 지정되지 않았다.

---

## 3. 우선순위별 작업

| 우선순위 | 작업 | 완료 근거 |
| --- | --- | --- |
| P0 | 조용한 구간 ASR 환각 재현·감소, 컴퓨터 소리/마이크/혼합 전사 누락·오인식 측정 | 조건별 원음 대조표와 회귀 결과 |
| P0 | 30~60분 실시간 통역의 지연·메모리·timeline 안정성 확인 | 시간대별 RSS, p50/p95 지연, 누락/오류·복구 기록 |
| P0 | 새 후보의 회의 녹음·가져오기·한국어 요약 E2E | 실제 앱과 localhost 결과 |
| P0 | Developer ID 서명·공증과 별도 깨끗한 Mac 설치·권한·첫 모델 다운로드 | 공증 결과와 clean-Mac 체크리스트 |
| P1 | 브라우저 마이크 및 가능한 시스템 공유 오디오의 권한별 E2E | 브라우저·OS별 성공/실패 증거 |
| P1 | 일본어 원문 수정·문맥 2턴·고유명사·부정·톤앤매너 샘플 평가 | 버전별 오류 분류와 전후 비교 |
| P2 | 데이터 보존·내보내기·삭제 사용자 정책과 복구 UX 정리 | 합의된 정책과 데이터 이전 테스트 |

## 4. 단계별 인계

| 단계 | 선행 증거 | 다음 단계 진입 |
|------|-----------|----------------|
| 1. 입력 정확도 | 원음 대조와 0청크/환각 재현 | 수정 후 조건별 재검증 |
| 2. 지속 안정성 | 30~60분 RSS·지연·누락 | 성능 수용 기준 판정 |
| 3. 업무 흐름 | 회의 녹음·가져오기·요약 E2E | 릴리스 후보 기능 동결 |
| 4. 배포 | Developer ID/공증, clean-Mac | 일반 배포 게이트 판정 |

---

## 5. 일정과 리소스

입력·장시간 시험에는 재현 가능한 일본어 음원과 Mac 오디오 장치가 필요하다. 배포 시험에는 별도 깨끗한 Mac과 Apple 서명 자격 증명이 필요하다. 완료 시간을 현 시점에 추정해 약속하지 않는다.

---

## 6. 리스크와 완화

무음 환각은 없는 발언의 생성, 혼합 입력 실패는 상대방 음성 누락, 메모리 증가는 장시간 세션 중단, ad-hoc 서명은 설치 신뢰성 문제로 이어질 수 있다. 각 위험은 샘플·측정·설치 증거가 생긴 뒤에만 해소로 표기한다.

---

## 7. 성과 측정

원음 대비 누락·고유명사·숫자·부정·어조 오류, p50/p95 표시 지연, 30~60분 RSS와 메모리 압력, 긴 timeline 재조회 성공률을 수집한다. 합격 기준은 기준선과 사용자 가치 판단 후 정한다.

---

## 8. 출고 판정과 관련 문서
