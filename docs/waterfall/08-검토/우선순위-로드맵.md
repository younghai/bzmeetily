# 우선순위 로드맵

이 목록은 검증·개선 순서이며 확정 일정이나 구현 완료 선언이 아니다.

| 우선순위 | 작업 | 완료 근거 |
| --- | --- | --- |
| P0 | 조용한 구간 ASR 환각 재현·감소, 컴퓨터 소리/마이크/혼합 전사 누락·오인식 측정 | 조건별 원음 대조표와 회귀 결과 |
| P0 | 30~60분 실시간 통역의 지연·메모리·timeline 안정성 확인 | 시간대별 RSS, p50/p95 지연, 누락/오류·복구 기록 |
| P0 | 새 후보의 회의 녹음·가져오기·한국어 요약 E2E | 실제 앱과 localhost 결과 |
| P0 | Developer ID 서명·공증과 별도 깨끗한 Mac 설치·권한·첫 모델 다운로드 | 공증 결과와 clean-Mac 체크리스트 |
| P1 | 브라우저 마이크 및 가능한 시스템 공유 오디오의 권한별 E2E | 브라우저·OS별 성공/실패 증거 |
| P1 | 일본어 원문 수정·문맥 2턴·고유명사·부정·톤앤매너 샘플 평가 | 버전별 오류 분류와 전후 비교 |
| P2 | 데이터 보존·내보내기·삭제 사용자 정책과 복구 UX 정리 | 합의된 정책과 데이터 이전 테스트 |

P0가 해결되지 않은 동안 일반 배포 승인을 내리지 않는다. 완료 기준의 측정값은 [테스트 계획](../05-테스트/테스트계획서.md)에 기록한다.
