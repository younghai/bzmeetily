# 단계별 검토 체크리스트

체크는 해당 버전의 실제 근거가 있을 때만 한다. 아래 미체크 항목은 현재 릴리스 판단의 남은 작업이며, 이 문서 작성으로 완료되지 않는다.

| 단계 | 확인 항목 | 현재 |
| --- | --- | --- |
| 기획 | 사용자 흐름·통역/녹음 분리, Apple Silicon/localhost 범위 정의 | 문서화 |
| 요구사항 | FR/NFR과 유스케이스·테스트 ID 연결 | 문서화 |
| 설계 | 네이티브/브라우저 캡처, 로컬 API, SQLite 경계 정리 | 문서화 |
| 구현 | 소스 경로·빌드 방법·회귀 검사 정리 | 문서화 |
| 테스트 | 빌드 Mac의 짧은 혼합 입력 timeline | RC4에서 제한적 확인 |
| 테스트 | 혼합 음원 전사/번역 정확도와 무음 환각 감소 | 미완료 |
| 테스트 | 브라우저 마이크·공유 음성 E2E | 미완료 |
| 테스트 | 새 후보의 회의 녹음/가져오기/요약 E2E | 미완료 |
| 테스트 | 30~60분 지연·RSS/메모리 안정성 | 미완료 |
| 배포 | RC6 DMG checksum·이미지·ad-hoc 서명·창 조작 | 확인 |
| 배포 | Developer ID 서명·공증·다른 Mac 첫 실행 | 미완료 |
| 운영 | 장애 대응/데이터 백업 절차 문서화 | 문서화, 현장 재현 미검증 |

각 항목의 증거는 [테스트 결과](../05-테스트/테스트결과보고서.md)와 [릴리스 상태](../../../reviews/STATE.md)를 확인한다. `문서화`는 실제 기능 승인과 구별한다.
