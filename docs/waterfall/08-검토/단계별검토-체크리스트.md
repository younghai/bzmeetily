## 1. 문서 개요

### 1.1 목적

단계별 완료 주장과 실제 증거를 구분해 점검한다.

### 1.2 적용 범위와 독자

기획·설계·구현·테스트·배포·운영 게이트를 포함한다. 제품 기획·개발·QA·릴리스 검토자가 사용한다.

### 1.3 기준과 판정

이 문서는 2026-09-25의 소스와 기록을 바탕으로 한 **검토 초안**이다. 문서화·코드 구현·실행 검증·일반 배포 승인은 서로 다른 상태다.

체크는 해당 버전의 실제 근거가 있을 때만 한다. 아래 미체크 항목은 현재 릴리스 판단의 남은 작업이며, 이 문서 작성으로 완료되지 않는다.

## 2. 요구사항 검토

| 확인 | 현재 |
|------|------|
| 사용자 문제와 통역/녹음 분리 | 문서화 |
| FR/NFR 수용 기준과 정책 ID | 문서화, 승인 기록 없음 |
| 혼합 입력·장시간 정확도 기준 | 측정 후 확정 필요 |

## 5. 테스트 검토

| 확인 항목 | 현재 |
|-----------|------|
| 빌드 Mac의 짧은 혼합 입력 timeline | RC4에서 제한적 확인 |
| 혼합 음원 전사/번역 정확도와 무음 환각 감소 | 미완료 |
| 브라우저 마이크·공유 음성 E2E | 미완료 |
| 새 후보의 회의 녹음/가져오기/요약 E2E | 미완료 |
| 30~60분 지연·RSS/메모리 안정성 | 미완료 |

`문서화`, `소스 검사 통과`, `실제 기기 통과`를 같은 체크로 합치지 않는다. 후보별 실행 결과를 [결과 보고서](../05-테스트/테스트결과보고서.md)에 연결한다.

---

## 6. 배포 검토

RC6의 DMG checksum·이미지·ad-hoc 서명은 일반 배포 게이트의 일부만 증명한다. Developer ID 서명·공증, 혼합 입력 정확도, 장시간 메모리, 새 후보 회의록 E2E, 별도 Mac의 첫 설치·권한은 미완료다.

---

## 7. 검토 완료와 승인

각 항목의 증거는 [테스트 결과](../05-테스트/테스트결과보고서.md)와 [릴리스 상태](../../../reviews/STATE.md)를 확인한다. `문서화`는 실제 기능 승인과 구별한다.

검토자의 이름·승인일·승인 범위는 아직 기록되지 않았다. 따라서 이 체크리스트는 일반 배포 승인서가 아니다. 미해결 P0 항목은 [로드맵](우선순위-로드맵.md)과 [배포 계획](../06-배포/배포계획서.md)에 남긴다.
