## 1. 문서 개요

### 1.1 목적

설치 후 시작·상태 확인·데이터 보존의 기본 절차를 제공한다.

### 1.2 적용 범위와 독자

앱과 같은 Mac의 localhost, 로컬 모델·회의 데이터를 대상으로 한다. 제품 기획·개발·QA·릴리스 검토자가 사용한다.

### 1.3 기준과 판정

이 문서는 2026-09-25의 소스와 기록을 바탕으로 한 **검토 초안**이다. 문서화·코드 구현·실행 검증·일반 배포 승인은 서로 다른 상태다.

## 2. 시스템 구성

| 구성 | 운영 확인 |
|------|-----------|
| Meetily2.app | 실행·모드 선택·권한 상태 |
| 로컬 API 3118 | `/api/local/status`의 모델 준비 상태와 회의 API의 DB 503을 각각 확인 |
| Whisper 8178 | 전사 모델 준비 |
| Ollama 11434 | `qwen3.5:4b` 번역·요약 모델 준비 |
| SQLite·오디오 | 회의 상세·오디오 재조회 |

---

## 3. 시작과 배포

개발 후보 사용자는 [저장소 README의 설치 절](../../../README.md)을 먼저 읽는다. DMG의 `Meetily2.app`을 Applications로 옮겨 실행하고 첫 실행에서 Whisper large-v3-turbo와 `qwen3.5:4b` 다운로드·권한 설정을 완료한다. 통역은 모드와 입력원을 고른 뒤 시작한다. 회의록은 별도의 녹음 또는 파일 가져오기 흐름에서 생성한다. 같은 Mac의 localhost UI는 앱과 로컬 서비스가 실행 중일 때만 `http://127.0.0.1:3118/`에서 사용한다.

새 후보 설치 시 이전 사용자 데이터를 보존한다. 서명·공증 상태와 후보 버전을 확인한 뒤에만 일반 설치 안내를 갱신한다.

---

## 4. 모니터링과 상태 확인

- UI에서 Whisper/Ollama 준비 상태, 입력원·권한, 캡처 중 여부, 전사/번역 처리 및 오류를 확인한다.
- `GET http://127.0.0.1:3118/api/local/status`는 로컬 서비스의 두 모델 상태를 반환한다. 503은 DB 준비 지연 가능성과 구분한다.
- `v2.0/scripts/smoke-test.sh`는 서비스·추론·loopback을 검사하되 실제 오디오 E2E 대신으로 사용하지 않는다.
- 포트 3118/8178/11434 충돌과 다른 Meetily 설치의 동시 실행을 확인한다.

실사용 품질 확인에는 모델 `ready`만으로 부족하다. 실제 입력 청크·일본어 원문·한국어 번역의 발생 시각과 누락 여부를 확인한다. 운영 중 개인 전사 텍스트는 공개 로그에 남기지 않는다.

---

## 5. 장애 대응

서비스 미기동, 0청크, 조용한 구간 환각, 과도한 지연, DB 503·요약 409를 서로 다르게 분류한다. 중요한 회의에서는 별도 원본 기록을 확보한다. 단계별 즉시 조치는 [장애 런북](../09-운영런북/장애대응-런북.md)을 따른다.

---

## 6. 백업과 복구

녹음·전사·요약 DB와 로컬 오디오가 사용자 Mac에 있다. 문제 재현 시 원본 데이터를 보존하고, 백업 사본에서만 마이그레이션·복구를 시험한다. 로그/이슈 공유 전 음성·전사·토큰·개인 경로를 제거한다. 모델 재설치나 포트 변경만으로 기존 회의 DB를 지우지 않는다. 구체적인 상황별 대응은 [장애 런북](../09-운영런북/장애대응-런북.md)에 있다.

**주의:** 개발 후보의 모델 출력과 시스템 오디오 권한 동작은 중요한 회의의 유일한 기록 수단으로 검증되지 않았다. 일반 배포 판정은 [배포 계획](배포계획서.md)을 따른다.

기본 DB와 sidecar 및 오디오 파일을 함께 다루어야 한다. 앱 종료 후 일관된 사본을 만들고 사본에서 회의·요약·오디오 조회를 확인한다. 원본을 테스트 초기화 대상으로 쓰지 않는다.

---

## 7. 보안 관리

로컬 API의 loopback 바인딩과 Host/Origin/변경 요청 헤더 검사를 유지한다. 개인 오디오, 모델, DB, 비밀값, 로그의 민감 데이터를 GitHub에 넣지 않는다. 외부 공유 전 로그와 화면 증거를 익명화한다.

## 8. 일상 점검표

| 확인 | 정상 판단 |
|------|-----------|
| 앱 시작 | 모드 선택이 보이고 자동 캡처 없음 |
| 모델 | Whisper·Ollama 상태가 준비됨 |
| 입력 | 선택한 마이크/컴퓨터 소리 청크가 실제 발생 |
| 통역 | 원문·번역·이전 timeline 카드가 유지 |
| 회의 | 저장 회의·오디오·요약 재조회 |
| 자원 | 장시간 RSS·지연·큐가 기록되고 이상 상승 분석 |
