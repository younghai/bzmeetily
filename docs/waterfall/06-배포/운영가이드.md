# 운영 가이드

## 시작과 사용

개발 후보 사용자는 [저장소 README의 설치 절](../../../README.md)을 먼저 읽는다. DMG의 `Meetily2.app`을 Applications로 옮겨 실행하고 첫 실행에서 Whisper large-v3-turbo와 `qwen3.5:4b` 다운로드·권한 설정을 완료한다. 통역은 모드와 입력원을 고른 뒤 시작한다. 회의록은 별도의 녹음 또는 파일 가져오기 흐름에서 생성한다. 같은 Mac의 localhost UI는 앱과 로컬 서비스가 실행 중일 때만 `http://127.0.0.1:3118/`에서 사용한다.

## 상태 확인

- UI에서 Whisper/Ollama 준비 상태, 입력원·권한, 캡처 중 여부, 전사/번역 처리 및 오류를 확인한다.
- `GET http://127.0.0.1:3118/api/local/status`는 로컬 서비스의 두 모델 상태를 반환한다. 503은 DB 준비 지연 가능성과 구분한다.
- `v2.0/scripts/smoke-test.sh`는 서비스·추론·loopback을 검사하되 실제 오디오 E2E 대신으로 사용하지 않는다.
- 포트 3118/8178/11434 충돌과 다른 Meetily 설치의 동시 실행을 확인한다.

## 데이터·복구

녹음·전사·요약 DB와 로컬 오디오가 사용자 Mac에 있다. 문제 재현 시 원본 데이터를 보존하고, 백업 사본에서만 마이그레이션·복구를 시험한다. 로그/이슈 공유 전 음성·전사·토큰·개인 경로를 제거한다. 모델 재설치나 포트 변경만으로 기존 회의 DB를 지우지 않는다. 구체적인 상황별 대응은 [장애 런북](../09-운영런북/장애대응-런북.md)에 있다.

**주의:** 개발 후보의 모델 출력과 시스템 오디오 권한 동작은 중요한 회의의 유일한 기록 수단으로 검증되지 않았다. 일반 배포 판정은 [배포 계획](배포계획서.md)을 따른다.
